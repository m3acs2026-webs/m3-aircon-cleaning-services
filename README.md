# FreshFlow Aircon Website

Static, Vercel-ready starter website inspired by the high-converting structure of iCare Aircon.

## Add your photos

Create an `images` folder and add your own photos there. Replace the placeholder hero block in `index.html` with an `<img>` when you are ready. Suggested filenames:

- `images/hero-technician.jpg`
- `images/service-cleaning.jpg`
- `images/service-repair.jpg`
- `images/service-maintenance.jpg`
- `images/before-after-01.jpg`

## Customize before launch

Update the business name, phone number, WhatsApp link, prices, service area, testimonials, and warranty wording in `index.html`.

This site has no build step: it can be deployed directly to Vercel by importing the GitHub repository and choosing the default settings.
